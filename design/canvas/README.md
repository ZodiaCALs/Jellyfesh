# Design canvas sources

Copies of the design canvas's files (the icon rounds and the Now Playing
style comparison), kept here so every repository version records the
design state. The live canvas is the review surface; these files are its
source.

* `canvas.json`: the canvas index (pages, artboards, notes).
* `*.dc.html`: one file per artboard.
* `assets.json`: maps each `/_blob/<id>` image reference in the artboards to
  the SVG in this repository that was uploaded under that id.

All titles, artwork and lyrics in the Now Playing mock-ups are placeholder
content written for the mock-ups, not real releases.
