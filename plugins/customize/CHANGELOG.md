# Changelog: Customize plugin

## 0.0.7 — 2026-11-18

* First release, with Jellyfesh v0.0.7 (plugin API 1.2, a Jellyfesh Pro
  capability): corners, glass, aurora, typeface, text size and density;
  the lyrics' weight, glow and highlight colour; the order of the sidebar
  and of Home, the Now Playing layout and the mini-player style. Settings in
  English, Chinese (Simplified and Traditional) and Japanese.
